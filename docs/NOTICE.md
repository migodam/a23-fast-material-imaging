# 公开材料与来源

本包的数值内核、代码和研究输入来自作者的既有A17–A22公开研究/已授权本地资产，保留MIT许可和上游commit。A23新增实现、冻结配置与首轮结果单独记录。

理论Markdown是实施前已完成的研究包，保留其原内容和历史`RESEARCH_MANIFEST.json`。其中“尚未实施/未来建议”描述理论包的形成时间；新的执行结果以README、A23_RESEARCH_REPORT_ZH.md和A23_GATE_DECISION.json为准。

第三方论文仅有书目信息和引用链接，不包含论文全文。NumPy/SciPy/PyTorch/matplotlib是环境依赖，没有打包第三方安装目录。公开包不含SSH连接配置、私钥、密码、聊天凭证或个人本机路径。少量失败栈/validator路径的公开副本只删去本机路径，保留数值、顺序、失败原因和费用；原字节保留在ignored私人存档，详见PUBLICATION_AUDIT.json。

所有输入对象和噪声/方向变体均注明历史暴露。失败和拒绝的图像会公开，发布本身不等于科学GO。没有新的SHA256检查；历史hash字段不删除，也不冒充本次重新校验。
